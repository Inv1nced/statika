Вариант 2 — разбор с рисунками

1) плоскость и направление 210 · 2) перлит в стали с 1,3 % C · 3) электронограмма и структура по светлому и тёмному полю

Задание 1. Плоскость (210) и направление [210]

Плоскость (210)
Направление [210]
  1. Плоскость: обратные величины 1/2, 1/1, 1/0 → отрезки x = ½, y = 1, z = ∞. Так как z = ∞, плоскость параллельна оси z — рисуем полосу вдоль z.
  2. Направление: числа без обратных, точка (2; 1; 0). Все три числа можно разделить на 2: вектор из начала координат в точку (1; ½; 0) — это то же направление [210].
  3. Проверка: [210] ⟂ (210). Вектор в плоскости (−½; 1; 0): (−½)·2 + 1·1 = 0 ✓.
На рисунке справа ось x отложена до 2 — там и стоит точка (2; 1; 0); в тетради в единичном кубе удобнее рисовать в точку (1; ½; 0), направление то же.

Задание 2. Количество перлита в стали с 1,3 % C

Структура: П + ЦII (заэвтектоидная, 1,3 % > 0,8 %) П = (6,67 − 1,3) / (6,67 − 0,8) = 5,37 / 5,87 ≈ 91,5 % ЦII = (1,3 − 0,8) / (6,67 − 0,8) = 0,5 / 5,87 ≈ 8,5 %
Доля = плечо напротив компонента ÷ весь отрезок. Для перлита напротив — плечо от сплава до цементита (5,37). Граница феррита (0,025 или 0,06) здесь не нужна.

Задание 3. Электронограмма и описание структуры

Так рисовать: центр — яркое пятно, вокруг кольца из точек и дуг неравномерной яркости (кольцо с утолщениями).

Что написать про структуру

  1. Светлое поле: много зёрен разного размера с разной яркостью; светлые зёрна с чёткими границами и тёмные участки со сложным контрастом (много дислокаций, изгибные контуры).
  2. Тёмное поле: почти всё поле тёмное, светятся отдельные зёрна и группы мелких точек. В выбранный рефлекс отражает только часть зёрен → ориентировки зёрен случайные.
  3. Вывод: поликристаллическая ультрамелкозернистая структура — мелкие зёрна и субзёрна разных размеров, разные ориентировки, в основном большеугловые границы.
  4. Электронограмма: кольца (много разно ориентированных кристаллитов). Кольца собраны из точек и дуг неравномерной яркости: яркие точки дают более крупные зёрна и субзёрна, тонкое ровное кольцо — самые мелкие зёрна. Кольцо с утолщениями → смешанная структура (зёрна + субзёрна).
  5. Радиусы колец (ОЦК): 110 : 200 : 211 : 220 = √2 : √4 : √6 : √8 ≈ 1 : 1,41 : 1,73 : 2 (по порядку от центра).
Электронограммы в варианте нет, поэтому тип структуры определяется по снимкам. Граница между «смешанной» и «субзёренной» структурой условна: если на слайдах преподавателя такой снимок подписан иначе — пиши по его подписи. Кольцо из точек и дуг на рисунке подходит в обоих случаях.
