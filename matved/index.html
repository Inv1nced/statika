Задание 2. Диаграмма Fe–C

Как читать. По горизонтали — состав (% углерода C), по вертикали — температура. Каждая область подписана тем, что в ней есть. Нас интересует область ниже 727 °C (после медленного охлаждения до комнатной температуры). Чёрточка на картинке — твоя сталь с содержанием углерода x.

Схема, шкала по X искажена для наглядности (как у тебя в тетради).

Два слова: фаза и структура

  • Фазы — химически и кристаллически однородные части. В Fe–C ниже 727 °C фаз всего две: феррит (Ф) (почти чистое железо, до 0,025 % C) и цементит (Ц) (Fe₃C, 6,67 % C).
  • Структура — то, что видно под микроскопом. Тут появляется перлит (П) — это не новая фаза, а «слоёный пирог» из пластинок Ф и Ц при 0,8 % C.
Поэтому в задаче два вопроса: «какие структуры и сколько» (Ф+П или П+Ц) и «какие фазы и сколько» (всегда Ф и Ц).
Типы стали по x:
  • x < 0,8 — доэвтектоидная: структура Ф + П
  • x = 0,8 — эвтектоидная: только П
  • x > 0,8 — заэвтектоидная: структура П + Ц (вторичный)
Выше ≈2,14 % C это уже чугун (появляется ледебурит), в задачах про сталь так не берут.

Правило рычага

Берёшь горизонталь через точку x. Её концы — составы «соседей». Доля одного соседа = противоположное плечо / вся длина.

доля левого = (R − x) / (R − L)
доля правого = (x − L) / (R − L)
Запомнить: чем ближе x к правому краю, тем больше правого. Поэтому его доля — это левый отрезок (L → x), «через крест».

Структуры

Фазы (рычаг всегда от 0,025 до 6,67)

Алгоритм для задачи «найди доли»:
  1. Найди x на оси: левее или правее 0,8? Это определяет структуры.
  2. Структуры: рычаг (0,025…0,8) для Ф+П или (0,8…6,67) для П+Ц.
  3. Фазы: рычаг (0,025…6,67), соседи Ф и Ц.
  4. Проверь: доли каждой пары дают 100 %.

Обратная задача: по доле найти %C

Ты знаешь долю компонента структуры и ищешь x. Это средневзвешенное: каждый компонент вносит свой углерод.

%C = Σ (доля компонента × его %C)

Углерод в компонентах: Ф ≈ 0,025 · П = 0,8 · Ц = 6,67.

Из тетради: 20 % Ф → 0,645 % C; 15 % Ц → 1,68 % C. Проверь себя ниже.

Задание 3. Рентген: параметр решётки

Рентгеновские лучи отражаются от семейств атомных плоскостей. Лучи усиливают друг друга, только если разность хода — целое число длин волн. Это закон Брэгга:

λ = 2 · d · sin θ

Второй луч проходит лишний путь 2d·sin θ. Для кубической решётки расстояние между плоскостями:

d = a / √(h² + k² + l²)
a = λ · √(h² + k² + l²) / (2 sin θ)
На дифрактограмме пик подписан 2θ, а в формулу идёт θ: делишь пик пополам. Это ты делаешь верно (37,9/2). λ = 1,54178 Å — излучение Cu Kα. 1 Å = 10⁻¹⁰ м. (hkl) — индексы Миллера плоскости, которые ты уже рисовал.
Задача 3 (прямая): найти a по пику
Задача 4 (обратная): найти положение пика 2θ
sin θ = λ·√(h²+k²+l²) / (2a)
2θ = 2 · arcsin(sin θ)
Не забудь умножить θ на 2 в конце. В тетради у тебя 27,95° · 2 = 55,9° — это верно.

Анализ профиля линии

Дифракционный пик стоит на фоне. Нужны три величины: высота пика I_пика, уровень фона I_фона и ширина пика B на половине его высоты (над фоном).

I_int = (I_пика − I_фона) / I_фона · B

Идея: берём насколько пик выше фона и умножаем на ширину — получается «площадь» линии. Чем больше фазы в образце, тем больше площадь её линий.

Определение соотношения фаз

Для каждой линии считаем I_int, потом складываем отдельно линии фазы A (α″) и фазы B (β):

A / B = Σ I_int(A) / Σ I_int(B)
