Цель работы

Изучить принципы построения изображений в геометрической оптике, смоделировать простые центрированные оптические системы и определить их основные параметры: фокусное расстояние, оптическую силу, увеличение.

1. Основные положения геометрической оптики

Геометрическая оптика — предельный случай волновой оптики: свет рассматривается как совокупность лучей. Приближение справедливо, если длина волны λ много меньше размеров линз и диафрагм, лучи параксиальные (идут близко к оси под малыми углами), а дифракцией и интерференцией можно пренебречь.

Световой луч — линия, перпендикулярная волновому фронту и показывающая направление распространения света. Пучок, лучи которого пересекаются в одной точке, — гомоцентрический; от бесконечно удалённого источника пучок параллельный.

Основные законы геометрической оптики:

  1. закон прямолинейного распространения света в однородной среде;
  2. закон независимости световых пучков;
  3. закон отражения: угол отражения равен углу падения;
  4. закон преломления: n₁ sin α = n₂ sin β.

Все они следуют из принципа Ферма: свет распространяется между двумя точками по пути, на прохождение которого требуется наименьшее время.

2. Оптические системы и тонкие линзы

Оптическая система — совокупность прозрачных сред, разделённых преломляющими поверхностями. Система центрированная, если центры всех поверхностей лежат на одной прямой — главной оптической оси. В идеальной системе каждая точка предмета изображается одной точкой.

Линза — прозрачное тело, ограниченное двумя сферическими поверхностями (или сферической и плоской). Линза тонкая, если её толщина много меньше радиусов кривизны поверхностей и расстояния до предмета. У тонкой линзы главные плоскости совпадают и проходят через оптический центр O; луч, идущий через O, не меняет направления.

Фокус F — точка на главной оси, в которой пересекаются лучи (или их продолжения), падавшие на линзу параллельно оси. Плоскость, проходящая через фокус перпендикулярно оси, — фокальная плоскость. Собирающая линза отклоняет лучи к оси, её фокус действительный и F > 0; рассеивающая — от оси, фокус мнимый и F < 0.

Оптическая сила линзы:

$$\Phi = \frac{1}{F} = \left(\frac{n_{\text{л}}}{n_{\text{ср}}} - 1\right)\left(\frac{1}{R_1} + \frac{1}{R_2}\right) \tag{1}$$

nл, nср — показатели преломления линзы и среды; R₁, R₂ — радиусы кривизны поверхностей (R > 0 для выпуклой поверхности). Единица — диоптрия: 1 дптр = 1 м⁻¹.

3. Формула тонкой линзы. Увеличение

$$\frac{1}{d} + \frac{1}{f} = \frac{1}{F} \tag{2}$$

d — расстояние от предмета до линзы, f — от линзы до изображения; отсчёт ведётся от оптического центра. Правило знаков: F > 0 у собирающей и F < 0 у рассеивающей линзы; f > 0 для действительного изображения (по другую сторону от линзы), f < 0 для мнимого; d < 0 для мнимого предмета.

Линейное увеличение — отношение размера изображения H к размеру предмета h:

$$\beta = \frac{H}{h} = -\frac{f}{d} \tag{3}$$

При β > 0 изображение прямое, при β < 0 — перевёрнутое.

Для построения изображения точки достаточно двух лучей: луч через оптический центр не преломляется, луч, параллельный оси, после линзы проходит через фокус (рис. 1). Действительное изображение можно получить на экране, мнимое видно только глазом.

4. Методы определения фокусного расстояния

Метод 1 — по расстояниям d и f

Получают на экране резкое изображение предмета, измеряют d и f; из (2):

$$F = \frac{df}{d + f} \tag{4}$$

Данные удобно обработать графически. Формула (2) в виде 1/d = Φ − 1/f — прямая в осях (1/f; 1/d), которая отсекает на обеих осях отрезок, равный Φ. Строят график по пяти положениям экрана и находят Φ и F = 1/Φ. Погрешность при Δd ≈ Δf:

$$\delta_F = \frac{\Delta F}{F} \approx \frac{\sqrt{d^4 + f^4}}{(d + f)^2}\cdot\frac{\Delta d}{F} \tag{5}$$

Точность метода падает с уменьшением фокусного расстояния.

Метод 2 — метод Бесселя

При неизменном расстоянии L между предметом и экраном есть два положения линзы, при которых изображение на экране резкое: увеличенное и уменьшенное (рис. 2). Расстояние между этими положениями равно l. Из d + f = L и (2) следует d² − Ld + LF = 0, откуда

$$d_{1,2} = \frac{L \mp \sqrt{L^2 - 4LF}}{2}, \qquad l = d_2 - d_1 = \sqrt{L^2 - 4LF}$$
$$F = \frac{L^2 - l^2}{4L} \tag{6}$$

Два положения существуют только при L > 4F. Метод точнее первого: измеряется перемещение линзы l, а не расстояния до её оптического центра, поэтому он подходит и для толстых линз. Погрешность при Δl ≈ ΔL, κ = l/L:

$$\delta_F \approx \frac{\Delta L}{L}\cdot\frac{\sqrt{(1 + \varkappa^2)^2 + 4\varkappa^2}}{1 - \varkappa^2} \tag{7}$$

Рис. 2. Метод Бесселя: при одном и том же L линза даёт увеличенное (1) и уменьшенное (2) изображение

Метод 3 — по смещению точки фокусировки

Применяется для длиннофокусной собирающей и рассеивающей линз. Короткофокусная линза даёт на экране резкое изображение. Исследуемую линзу ставят перед экраном на расстоянии d от него — это изображение становится для неё мнимым предметом. Экран передвигают до резкости; новое расстояние от линзы до экрана — f (в таблицах 3, 4 это l = x₃′ − x₄). Из (2) с мнимым предметом (−1/d + 1/f = 1/F):

$$F = \frac{df}{d - f} \tag{8}$$

Для собирающей линзы f < d и F > 0, для рассеивающей f > d и F < 0. Погрешность при Δd ≈ Δf:

$$\delta_F \approx \frac{\sqrt{d^4 + f^4}}{(d - f)^2}\cdot\frac{\Delta d}{|F|} \tag{9}$$

5. Система из двух линз

Оптическая сила двух тонких линз, расположенных на расстоянии a друг от друга:

$$\Phi = \Phi_1 + \Phi_2 - a\,\Phi_1\Phi_2 \tag{10}$$

Угловое увеличение — отношение угла, под которым предмет виден через систему, к углу, под которым он виден без неё: Γ = tg ψ′ / tg ψ. Для зрительной трубы, у которой задний фокус объектива совпадает с передним фокусом окуляра:

$$\Gamma = \frac{F_{\text{об}}}{|F_{\text{ок}}|} \tag{11}$$

Предельное угловое расстояние между точками, которые объектив диаметром D ещё разрешает (критерий Рэлея):

$$\psi_{\min} = 1{,}22\,\frac{\lambda}{D} \tag{12}$$
