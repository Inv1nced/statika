Расчётные формулы

$$R_x = R\,\frac{l_1}{l_2} \tag{18}$$
$$\Delta R_x = \left(\frac{\Delta l}{l_1} + \frac{\Delta l}{l_2}\right) R_x, \qquad \delta = \frac{\Delta R_x}{R_x}\cdot 100\% \tag{19}$$
$$R_{\text{теор}} = \rho\,\frac{l}{S} = \frac{4\rho l}{\pi d^{2}}, \qquad S = \frac{\pi d^{2}}{4} \tag{6}$$
$$R_{\text{посл}} = R_2 + R_5 \tag{7}$$
$$\frac{1}{R_{\text{пар}}} = \frac{1}{R_2} + \frac{1}{R_5} \;\Rightarrow\; R_{\text{пар}} = \frac{R_2 R_5}{R_2 + R_5} \tag{8}$$
$$\varepsilon = \frac{R_x - R_{\text{теор}}}{R_{\text{теор}}}\cdot 100\%$$

Влияние эталонного R (задание, п. 3), L = 1000 мм:

$$\delta = \frac{\Delta l}{L}\left(2 + \frac{R_x}{R} + \frac{R}{R_x}\right), \qquad \delta_{\min} = \frac{4\Delta l}{L} = 0{,}2\% \ \text{при}\ R = R_x$$

Контрольные вопросы

  1. Ток — упорядоченное движение зарядов. Условия: свободные носители заряда и электрическое поле; для постоянного тока — замкнутая цепь с источником.
  2. Сторонние силы — неэлектростатические (химические, электромагнитные), разделяют заряды в источнике. ЭДС — их работа по переносу единичного положительного заряда: ε = Aстор/q. ЭДС и напряжение — работа на единицу заряда, Дж/Кл = В.
  3. Однородный участок: I = U/R. Неоднородный: IR = φ₁ − φ₂ + ε₁₂. Напряжение — работа кулоновских и сторонних сил по переносу единичного положительного заряда: U₁₂ = φ₁ − φ₂ + ε₁₂.
  4. Закон сохранения заряда: заряд в узле не накапливается, поэтому ΣIk = 0.
  5. IR берут с «+», если ток совпадает с направлением обхода; ЭДС с «+», если обход внутри источника идёт от «−» к «+». В основе — закон сохранения энергии.
  6. При балансе ток через амперметр равен 0, φC = φD, отсюда Rx = R·l₁/l₂; ЭДС и амперметр на результат не влияют. Погрешность δ = (Δl/L)·(2 + Rx/R + R/Rx) минимальна при R ≈ Rx, когда бегунок в середине (δmin = 0,2 %). Погрешность самого R входит в Rx целиком.
