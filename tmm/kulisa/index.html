Кулиса: план скоростей по пунктам

С нуля и по шагам: что такое кулиса, откуда у камня «две скорости», какие две прямые проводить, как потом найти ω и точку B. Дальше разберём механизм из КР целиком, второй тип кулисы, шпаргалку и тест.

Всё главное — в трёх строках
  1. В точке A сидят три точки трёх звеньев: A1 (кривошип) и A2 (камень) движутся одинаково, A3 (кулиса) — иначе.
  2. VA3 = VA2 + VA3A2: через a2 — прямая ∥ кулисе, через p — прямая ⊥ кулисе. Пересечение — a3.
  3. ω3 = VA3 / lO2A (O2A меряем на чертеже), ω2 = ω3. Остальные точки кулисы лежат на луче pa3, их находим по подобию.

Слайд 2 · смотрим, как он двигается

Как устроен кулисный механизм

Сначала посмотри на движение, потом будем строить. Кнопка ❚❚ останавливает, ползунок двигает кривошип.

  1. Кривошип 1 (O1A) — ведущее звено. Крутится вокруг O1 с заданной ω1.
  2. Камень 2 — маленький ползунок. Шарниром надет на палец кривошипа в точке A и сидит в прорези кулисы.
  3. Кулиса 3 (O2B) — длинное звено с прорезью. Качается вокруг неподвижной опоры O2.
  4. Кривошип тащит камень по окружности. Камень давит на кулису и поворачивает её — и одновременно едет вдоль неё. Под рисунком написано, куда он сейчас скользит.
  5. O2A всё время меняется (оранжевый размер). Поэтому её нет в условии: её меряют на своём чертеже в заданном положении.
Слайд 3 · главный трюк

В точке A — три разные точки

Сейчас все три в одном месте, но принадлежат разным звеньям и движутся по-разному. Весь кулисный план держится на этом.

  1. A1 — точка кривошипа. Её скорость считаем сразу: VA1 = ω1·lO1A, направлена ⊥ O1A в сторону вращения.
  2. A2 — точка камня. Камень надет на палец кривошипа (шарнир), поэтому едет вместе с A1: VA2 = VA1. На плане a1 и a2 — одна точка.
  3. A3 — точка кулисы, которая сейчас под камнем. Кулиса вращается вокруг O2, значит VA3 ⊥ O2A.
  4. VA3 ≠ VA2, потому что камень скользит по кулисе. Разница между ними — скорость скольжения, и она направлена вдоль кулисы.
Откуда «две скорости»
Скорость у камня одна — VA2. Но кулиса под ним движется иначе — VA3. Нам нужна именно VA3: по ней найдём, как крутится кулиса.
Слайд 4 · почему перпендикуляры

Откуда «две скорости»: раскладываем скорость камня

Камень может давить на кулису только поперёк неё: вдоль он просто проскальзывает. Поэтому скорость камня делится на две части.

  1. VA2 известна целиком: ⊥ кривошипу, длина ω1·lO1A.
  2. Часть поперёк кулисы поворачивает кулису — это и есть VA3 (⊥ O2A).
  3. Часть вдоль кулисы ничего не поворачивает — это скольжение, VA3A2 (∥ кулисе).
  4. Вместе: VA3 = VA2 + VA3A2 — прямоугольный треугольник, прямой угол у конца VA3.
  5. План скоростей на втором рисунке — тот же самый треугольник, только он начинается в полюсе p.
  6. Поймай ползунком крайние случаи: кривошип ⊥ кулисе → VA3 = 0 (кулиса в крайнем положении, на миг останавливается); кривошип вдоль кулисы → скольжения нет.
Слайд 5 · уравнение → две прямые

Векторное уравнение: что известно

VA3 = VA2 + VA3A2
ВекторВеличинаНаправлениеНа плане
VA2 (= VA1)ω1·lO1A — известна⊥ O1A, по ω1из p в a2
VA3A2?∥ кулисе O2Bначинается в a2
VA3?⊥ O2Aиз p — абсолютная
  1. Одна черта под вектором — известно только направление, две черты — известно всё.
  2. Неизвестны две длины, а направления известны. Значит, решаем построением: две прямые и их пересечение.
  3. Через p — прямая для абсолютной скорости VA3. Абсолютные скорости на плане всегда начинаются в полюсе.
  4. Через a2 — прямая для относительной VA3A2: в уравнении она прибавляется к VA2, значит начинается там, где VA2 кончается.
  5. Почему ∥ кулисе: в прорези камень может двигаться относительно кулисы только вдоль неё. Почему ⊥ O2A: кулиса вращается вокруг O2, а скорость точки вращающегося звена всегда ⊥ радиусу.
Слайд 6 · построение

Строим точку a3 по шагам

Механизм — тот же, что в разборе КР по ТЗ: O1A = 60 мм, O2 на 130 мм ниже и 10 мм правее O1, O2B = 240 мм, φ = 60°, ω1 = 10 рад/с по часовой. Жми «Дальше ›».

Чем чертить точно

  • Параллель: угольник катетом на линию-образец, линейку к гипотенузе. Держим линейку, сдвигаем угольник до нужной точки и проводим.
  • Перпендикуляр: та же установка, но проводим по второму катету.
  • Шаги 3 и 4 — это одна установка угольника: катет вдоль кулисы → сдвиг до a2 (параллель) → сдвиг до p (перпендикуляр).
  • Длины — циркулем по линейке от отметки 10 мм, а не от края.
Слайд 7 · угловая скорость и подобие

ω3, её направление и точка B

  1. ω3 = VA3 / lO2A. Делим на O2A — расстояние до камня, а не на длину кулисы.
  2. Направление: вектор pa3 переносим в точку A схемы и смотрим, куда он крутит кулису вокруг O2.
  3. ω2 = ω3: камень не может провернуться в прорези.
  4. Любая точка кулисы лежит на луче pa3: pb = pa3·O2B/O2A. Точка по другую сторону от O2 — в обратную сторону от p.
  5. S3 — середина O2B, значит s3 — середина pb.
Слайд 8 · кулиса + шатун + ползун

Механизм как в КР: сначала схема

  1. Масштаб «на всю площадь»: μl подбираем так, чтобы схема заняла верхнюю половину листа.
  2. Ставим O1, от неё O2 по координатам — угольником, без транспортира.
  3. Луч под углом φ, засечка циркулем O1A — получили точку A.
  4. Кулиса — это прямая через O2 и A. Её не откладывают по углу: сначала A, потом линейкой через O2 и A, потом засечка O2B на этой прямой.
  5. Засечка BC на направляющей — точка C. Сразу меряем O2A: она понадобится для ω3.
Слайд 9 · весь план с числами

Механизм как в КР: весь план скоростей

  1. a1 = a2, потом a3 двумя прямыми — как на слайде 6.
  2. b — на луче pa3 по подобию (слайд 7).
  3. Дальше обычная группа «шатун + ползун»: VC = VB + VCB → через b ⊥ BC, через p ∥ направляющей.
  4. Центры масс — середины отрезков плана: s1 на pa1, s3 на pb, s4 на bc.
  5. ω3 = ω2 = VA3/lO2A; ω4 = VCB/lBC. Направления — переносом векторов на схему.

Слайд 10 · другой вид кулисы

Второй тип: камень на стойке

Камень закреплён шарниром на стойке, а кулиса проезжает сквозь него. Принцип тот же: неизвестную точку описываем двумя способами — получаем две прямые.

  1. Неизвестна B2 — точка кулисы, которая сейчас внутри камня.
  2. Кулиса — твёрдое звено: VB2 = VA + VB2A, VB2A ⊥ AB → через a ⊥ AB.
  3. Кулиса скользит в камне: VB2 = VB3 + VB2B3, VB3 = 0 → через p ∥ AB.
  4. ω2 = VB2A / lAB, AB снова меряем на чертеже. ω3 = ω2.
Сравни с первым типом
«∥» и «⊥» поменялись местами. Правило одно на оба случая: через p — как точка движется относительно стойки, через известную точку — как она движется относительно другого звена.

Частые ошибки

✗ VA3 ⊥ O1A → ✓ VA3 ⊥ O2A. ⊥ кривошипу — это VA2.
✗ Прямую ∥ кулисе провести через p → ✓ через a2: относительная скорость начинается в конце известного вектора.
✗ ω3 = VA3 / длина кулисы → ✓ делить на lO2A — расстояние до камня. На O2B делят только VB.
✗ Искать a2 отдельно → ✓ a1 = a2, это одна точка.
✗ Строить b новыми прямыми → ✓ b на луче pa3: pb = pa3·O2B/O2A.
✗ Забыть про камень → ✓ ω2 = ω3, пишем в ответ.

Что написать на листе с формулами

VA1 = ω1·lO1A;  VA2 = VA1
VA3 = VA2 + VA3A2;  ⊥ O2A · ⊥ O1A · ∥ O2B
VA3 = pa3·μV;  ω3 = ω2 = VA3 / lO2A
pb = pa3·lO2B / lO2A;  VB = pb·μV
VC = VB + VCB;  ∥ направл. · известна · ⊥ BC
ω4 = VCB / lBC

Проверка без плана: VA3 = VA2·cos α, где α — угол между кривошипом O1A и кулисой.
