  • Разбор + конструктор плана. Для каждого механизма со слайда — готовый пошаговый разбор, а под ним конструктор. Ты сам выбираешь, через какую точку плана и в каком направлении провести каждую прямую, а страница проверяет. Ровно то, что делаешь на КР с линейкой.
  • Тесты на понимание: почему прямая именно такая.

Векторные уравнения

Весь план скоростей — это графическое решение векторных уравнений. Поэтому начинаем с них.

Что нужно знать

  • Вектор задаётся двумя параметрами: величиной и направлением.
  • Сумма c = a + b: второй вектор начинаем из конца первого, а сумма идёт из начала первого в конец второго.
  • Несколько векторов складываем цепочкой, каждый из конца предыдущего, в любом порядке. Сумма — из начала первого в конец последнего.
  • Черты под вектором показывают, сколько его параметров известно. a — известны и величина, и направление. x — только направление.
  • На плоскости векторное уравнение решается, если неизвестных не больше двух.

Главный приём (он же — весь план скоростей)

a + x = b + y

Из общей точки откладываем известные a и b. Через конец a проводим прямую в направлении x, через конец b — в направлении y. Где прямые пересеклись, там и заканчиваются обе части. Так находится каждая точка плана скоростей.

Упражнения 1–5 со слайдов

Реши на бумаге, потом открой решение и дойди до последнего шага — упражнение засчитается.

Первый план: кривошипно-ползунный механизм

План скоростей — чертёж, на котором в выбранном масштабе изображены векторы скоростей разных точек звеньев механизма в данный момент времени.

Правила, которые понадобятся

  1. Полюс p — точка, из которой проводят все абсолютные скорости (относительно стойки). Неподвижные точки на плане лежат в полюсе.
  2. Ведущая точка: VA = ω1·lOA, вектор ⊥ кривошипу в сторону его поворота. Масштаб: μV = VA / pa, (м/с)/мм.
  3. Плоское движение звена складывается из поступательного движения вместе с одной из его точек и поворота вокруг неё. Отсюда главная формула:
    VB = VA + VBA
    VBA — относительная скорость поворота B вокруг A, она ⊥ AB.
  4. Ползун на неподвижной направляющей: его абсолютная скорость ∥ направляющей и выходит из полюса.
  5. Центры масс: VS1 = ½·VA; VS2 = VA + ½·VBA, то есть s2 — середина ab.
  6. Угловая скорость: ω2 = VBA / lAB. Направление — по направлению относительной скорости VBA.
  7. На плане подписывают только строчные буквы — концы векторов. Скорость любой точки X: VX = μV·|px|.

Разбор по слайдам

На слайде 14 есть ещё одна идея: если «перевернуть» механизм и сделать стойкой ползун, план линейных скоростей останется тем же — поменяется только полюс (теперь в точке b). Для КР это не нужно, но объясняет, почему важно, относительно чего мы меряем скорости.

Четырёхзвенник и свойство подобия

Что нового

  • Вместо ползуна — коромысло CB, которое вращается вокруг неподвижной C. Поэтому VB — абсолютная скорость поворота B вокруг C: ⊥ BC и из полюса.
  • Звено 2 — треугольная пластина ABK. Скорость третьей точки K нужно найти, не составляя новую диаду.

Свойство подобия

Концы векторов скоростей точек одного звена образуют на плане фигуру, подобную этому звену (и повёрнутую на 90° в сторону его ω). Треугольник abk подобен ABK. Поэтому k находят двумя прямыми: через a ⊥ AK и через b ⊥ BK.

На лекции то же самое выводили через мгновенный центр вращения W звена ABK. Это пересечение перпендикуляров к известным скоростям VA и VB, то есть точка пересечения прямых OA и CB. Скорость любой точки звена перпендикулярна её радиусу до W: VK ⊥ WK.

  • Все неподвижные точки — O, C и мгновенный центр W — на плане лежат в полюсе.
  • Центры стержней — середины: s1 — середина pa, s3 — середина pb. Центр треугольного звена s2 находят по подобию.
  • ω2 = VBA/lAB = VKA/lAK = VKB/lBK; ω3 = VB/lBC.

Шестизвенники из двух диад

Это уже формат КР. Механизм собран так: кривошип → первая диада → вторая диада. План строят в том же порядке, в каком присоединены группы. Для каждой новой точки — два уравнения, две прямые, пересечение.

Шпаргалка: какие прямые для какой точки

  • Шарнир между двумя звеньями, у второго один конец неподвижен: через известную точку ⊥ первого звена, через p ⊥ второго.
  • Ползун на неподвижной направляющей: через известную точку ⊥ шатуна, через p ∥ направляющей.
  • Третья точка жёсткого звена (треугольник): через две известные точки ⊥ соответствующих сторон (подобие).
  • Точка на отрезке звена (C на AB): делит отрезок плана в той же пропорции.

Кулисы

Кулиса — подвижное звено, которое образует поступательную пару с другим подвижным звеном (камнем).

Сложное движение

Vабс = Vпер + Vотн

В точке A, где камень сидит на кулисе, рассматриваем три разные точки:

  • A1 — на кривошипе 1;
  • A2 — на камне 2. Он шарнирно сидит на кривошипе и ходит по той же окружности, поэтому VA2 = VA1: на плане a1 и a2 — одна точка;
  • A3 — на кулисе 3, под камнем.
VA3 = VA2 + VA3A2

VA3A2 — скорость кулисы относительно камня, ∥ кулисе. VA3 — скорость поворота точки кулисы вокруг O2, ⊥ O2A и из полюса.

  • Скорости точек вращающейся кулисы пропорциональны расстоянию до центра: pb = pa3·O2B/O2A.
  • ω2 = ω3 = VB/lO2B = VA3/lO2A: камень поворачивается вместе с кулисой.

Разбор: кулисный механизм с шатуном

Второй случай: камень шарнирно на стойке

В точке B соединяются три звена: кулиса 2, камень 3 и стойка 0. Из плоского движения кулисы: VB2 = VA + VB2A. Из сложного движения: VB2 = VB3 + VB2B3, а VB3 = VB0 = 0. Значит, b2 лежит на пересечении двух прямых: через a ⊥ AB и через p ∥ AB. Точку C находим по подобию: ac/ab2 = AC/AB.

Кулисы в шестизвенниках

Три механизма из примеров. Ничего нового — всё те же два уравнения на точку. Только надо внимательно смотреть, по чему скользит камень и как движется звено, к которому он прицеплен.

  • Звено, которое ходит в направляющей поступательно (штанга): у всех его точек одинаковая скорость, ∥ направляющей. На плане это одна точка: d = c5.
  • Камень скользит вдоль звена: относительная скорость ∥ этому звену и проводится через точку плана того звена, по которому он скользит.
  • Ведущим может быть и ползун — тогда его скорость задана сразу.

Группа III порядка

Звено 3 (BC) — базисное: к нему присоединены три поводка — камень 2 с кривошипом, коромысло 4 и ползун 5. Ни одну точку нельзя найти по отдельности.

VA3 = VA2 + VA3A2

У VA3 неизвестны и величина, и направление (траектория A3 неизвестна). Всего неизвестных больше двух — графически не решить. На лекции было три выхода:

  1. Мгновенный центр вращения базисного звена. P — пересечение перпендикуляров к скоростям двух точек звена: к VC (горизонтальна) и к VB (⊥ O2B). Тогда VA3 ⊥ AP. Минус: P не всегда можно найти, и он может уйти за край листа.
  2. Особая точка — точка Ассура (универсальный способ). Это точка базисного звена на пересечении линий двух поводков. Если поводок — ползун, его линию проводят перпендикулярно оси ползуна. Достраиваем K так, чтобы AK ⊥ BC, а BK ⊥ VB. Тогда в VK = VA2 + VA3A2 + VKA3 два последних слагаемых лежат на одной прямой ∥ BC, а VK ⊥ BK. Остаются две неизвестные.
  3. Обратный порядок. Начинаем с ведомого звена: pb ⊥ O2B произвольной длины. Строим c и a3, потом a1. Масштаб определяется в конце, по длине pa1.

Перед КР

Алгоритм на любой механизм

  1. Пронумеруй звенья, найди ведущее и группы Ассура (порядок присоединения).
  2. Полюс p. Все неподвижные точки — в нём.
  3. pa ⊥ кривошипу по ω1; μV = VA/pa.
  4. Для каждой новой точки — два уравнения. В каждом одно слагаемое уже на плане, у второго известно только направление. Две прямые → пересечение.
  5. Абсолютные скорости — из p. Относительные — через уже найденную точку.
  6. Камень: a1 = a2; относительная скорость ∥ кулисе.
  7. Остальные точки звеньев и центры масс — по подобию.
  8. ω = (относительная скорость)/(длина). Направление — переносом вектора в точку схемы.
