# Тренажёр по статике

Сайт для подготовки к пересдаче по теоретической механике (статика), 30 сентября.
Один файл `index.html`, работает без сервера — можно просто открыть в браузере.

## Как выложить на GitHub Pages

1. github.com → **New repository** → имя, например `statika` → **Public** → **Create repository**.
2. На странице репозитория: **Add file → Upload files** → перетащи `index.html` и этот `README.md` → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/statika/`.

## Что внутри

- **Моменты** — тренажёр знака и плеча на изогнутых стержнях (П, Г, Ш, ступенька, крюк) и режим «уравнение моментов целиком».
- **Как решать** — правило знака, почему изгиб стержня не важен, алгоритм, разборы с одним и двумя шарнирами, оформление на экзамене, самопроверка.
- **Задачи** — примеры 2.1–2.4 из методички, две задачи со слайдов и генератор: один шарнир, два шарнира (перевёрнутая Ш, П, балка), балки. Проверка ответов и решение по шагам с объяснением знака каждого слагаемого.
- **Теория** — 66 тем по лекциям TM_1–TM_6. У каждой темы: суть в одну строку, иллюстрация (44 схемы), формула, «как запомнить», типичная ловушка, **пример для ответа** (с числами, многие — прямо со слайдов) и **что нарисовать на экзамене**, плюс подробный текст. Режимы: учить по темам, читать всё, интервальные карточки (133, из них 16 с картинками), тесты по блокам (64 вопроса), итоговый тест, шпаргалка на одном экране, 28 билетов с ответом за минуту, карта курса.
- **Пробник** — два вопроса по теории и задача, 90 минут, эталонные ответы после сдачи (вместе с примерами и рисунками).

Прогресс хранится в браузере (localStorage).
