Ступенчатый брус с жёсткой заделкой слева, три участка. На первом участке — распределённая нагрузка \(q\), сосредоточенные силы \(F_1\), \(F_2\), \(F_3\). Требуется построить эпюру продольной силы, подобрать квадратное сечение каждого участка, построить эпюру перемещений и проверить жёсткость.

Допускаемое удлинение (укорочение) участка \([\Delta l] = 10^{-3}\cdot l\). Модуль упругости: в восьмой колонке таблицы стоит 10, то есть \(E = 10\cdot10^4\) МПа \(= 1\cdot10^5\) МПа.

1. Запишем аналитические выражения продольных сил по участкам и вычислим их на границах. Построим эпюру продольной силы

1.1. Составим уравнение для суммы проекций сил на ось Z для всего бруса и вычислим опорную реакцию

Направим реакцию заделки \(Z_A\) по оси \(z\). Равнодействующая распределённой нагрузки на первом участке \(q\,l_1\).

$$\sum F_z = 0:\qquad Z_A - q\,l_1 - F_1 + F_2 + F_3 = 0,$$ $$Z_A = q\,l_1 + F_1 - F_2 - F_3 = 100\cdot0{,}9 + 37 - 29 - 7 = 91\ \text{кН}.$$

\(Z_A = 91\) кН. Знак «плюс» — реакция направлена так, как показано на схеме (по оси \(z\)).

1.2. Рассмотрим каждый участок бруса для нахождения значений продольной силы

Мысленно рассекаем брус на каждом участке и рассматриваем левую отсечённую часть. Продольную силу \(N_z\) направляем от сечения (растяжение — плюс).

Первый участок: \(0 \le z \le l_1 = 0{,}9\) м

$$Z_A - q\,z + N_z^{I} = 0\quad\Rightarrow\quad N_z^{I} = q\,z - Z_A = 100z - 91.$$ $$z = 0:\ N_z^{I} = -91\ \text{кН};\qquad z = 0{,}9\ \text{м}:\ N_z^{I} = 100\cdot0{,}9 - 91 = -1\ \text{кН}.$$

На первом участке продольная сила меняется по линейному закону, участок сжат.

Второй участок: \(l_1 \le z \le l_1 + l_2\), то есть \(0{,}9 \le z \le 2{,}9\) м

$$Z_A - q\,l_1 - F_1 + N_z^{II} = 0\quad\Rightarrow\quad N_z^{II} = q\,l_1 + F_1 - Z_A = 90 + 37 - 91 = 36\ \text{кН}.$$

Продольная сила постоянна, участок растянут.

Третий участок: \(l_1 + l_2 \le z \le l_1 + l_2 + l_3\), то есть \(2{,}9 \le z \le 3{,}5\) м

$$Z_A - q\,l_1 - F_1 + F_2 + N_z^{III} = 0\quad\Rightarrow\quad N_z^{III} = q\,l_1 + F_1 - F_2 - Z_A = 90 + 37 - 29 - 91 = 7\ \text{кН}.$$

Проверка по правой отсечённой части: \(N_z^{III} = F_3 = 7\) кН — совпадает. Участок растянут.

2. Подбор сечений бруса по участкам

2.1. Предположим, что брус имеет сечение квадрат со стороной \(a\), тогда площадь данного сечения будет рассчитываться по формуле \(A = \dfrac{N_z}{[\sigma]}\), а сторона бруса \(a = \sqrt{A}\)

Для растянутых участков берём \([\sigma]_\text{р} = 60\) МПа, для сжатых — \([\sigma]_\text{с} = 100\) МПа. В расчёт подставляем модуль продольной силы.

2.2. Рассмотрим каждый участок

Первый участок (сжатие)

$$A_I' = \frac{|N_z^{I}(0)|}{[\sigma]_\text{с}} = \frac{91\cdot10^3}{100\cdot10^6} = 9{,}1\cdot10^{-4}\ \text{м}^2,\qquad A_I'' = \frac{|N_z^{I}(l_1)|}{[\sigma]_\text{с}} = \frac{1\cdot10^3}{100\cdot10^6} = 0{,}1\cdot10^{-4}\ \text{м}^2.$$

Из двух полученных значений выберем наибольшую и посчитаем сторону бруса \(a\):

$$A_I = 9{,}1\cdot10^{-4}\ \text{м}^2 = 9{,}1\ \text{см}^2,\qquad a_1 = \sqrt{9{,}1\cdot10^{-4}} = 0{,}0302\ \text{м} = 30{,}2\ \text{мм}.$$

Второй участок (растяжение)

$$A_{II} = \frac{N_z^{II}}{[\sigma]_\text{р}} = \frac{36\cdot10^3}{60\cdot10^6} = 6\cdot10^{-4}\ \text{м}^2 = 6\ \text{см}^2,\qquad a_2 = \sqrt{6\cdot10^{-4}} = 0{,}0245\ \text{м} = 24{,}5\ \text{мм}.$$

Третий участок (растяжение)

$$A_{III} = \frac{N_z^{III}}{[\sigma]_\text{р}} = \frac{7\cdot10^3}{60\cdot10^6} = 1{,}17\cdot10^{-4}\ \text{м}^2 = 1{,}17\ \text{см}^2,\qquad a_3 = \sqrt{1{,}17\cdot10^{-4}} = 0{,}0108\ \text{м} = 10{,}8\ \text{мм}.$$

3. Рассчитаем перемещение поперечных сечений бруса

В основе решения задачи лежат 2 принципа. Принцип Бернулли и принцип Сен-Венана.

Принцип Бернулли (гипотеза плоских сечений): сечения, плоские до деформации, остаются плоскими и перпендикулярными оси бруса, поэтому напряжения по сечению распределены равномерно, \(\sigma = N_z/A\). Принцип Сен-Венана: вдали от места приложения нагрузки распределение напряжений не зависит от способа её приложения, поэтому силу можно считать приложенной в точке.

Модуль упругости \(E = 1\cdot10^5\) МПа \(= 10^{11}\) Па. Ось \(z\) — от заделки, в заделке перемещение равно нулю.

Первый участок (нагрузка распределённая, \(N_z\) переменная)

$$\delta(z) = \int_0^z \frac{N_z^{I}\,dz}{E A_I} = \frac{1}{E A_I}\int_0^z (q z - Z_A)\,dz = \frac{1}{E A_I}\left(\frac{q z^2}{2} - Z_A z\right).$$ $$E A_I = 10^{11}\cdot9{,}1\cdot10^{-4} = 9{,}1\cdot10^{7}\ \text{Н}.$$ $$z = 0:\ \delta = 0;\qquad z = 0{,}45\ \text{м}:\ \delta = \frac{50\cdot10^3\cdot0{,}45^2 - 91\cdot10^3\cdot0{,}45}{9{,}1\cdot10^7} = -3{,}39\cdot10^{-4}\ \text{м};$$ $$z = l_1 = 0{,}9\ \text{м}:\ \delta_1 = \frac{50\cdot10^3\cdot0{,}81 - 91\cdot10^3\cdot0{,}9}{9{,}1\cdot10^7} = \frac{-41\,400}{9{,}1\cdot10^7} = -4{,}55\cdot10^{-4}\ \text{м} = -0{,}455\ \text{мм}.$$

Второй участок (\(N_z\) постоянна)

$$\delta_2 = \frac{N_z^{II}\,l_2}{E A_{II}} = \frac{36\cdot10^3\cdot2}{10^{11}\cdot6\cdot10^{-4}} = 1{,}2\cdot10^{-3}\ \text{м} = 1{,}2\ \text{мм}.$$ $$\delta(l_1 + l_2) = \delta_1 + \delta_2 = -0{,}455 + 1{,}2 = 0{,}745\ \text{мм}.$$

Третий участок (\(N_z\) постоянна)

$$\delta_3 = \frac{N_z^{III}\,l_3}{E A_{III}} = \frac{7\cdot10^3\cdot0{,}6}{10^{11}\cdot1{,}17\cdot10^{-4}} = 3{,}6\cdot10^{-4}\ \text{м} = 0{,}36\ \text{мм}.$$ $$\delta(l_1 + l_2 + l_3) = \delta_1 + \delta_2 + \delta_3 = -0{,}455 + 1{,}2 + 0{,}36 = 1{,}105\ \text{мм}.$$

4. Нахождение экстремума

Экстремум на эпюре перемещений может быть только там, где \(N_z = 0\), то есть на первом участке:

$$N_z^{I} = q z_0 - Z_A = 0\quad\Rightarrow\quad z_0 = \frac{Z_A}{q} = \frac{91}{100} = 0{,}91\ \text{м}.$$

\(z_0 = 0{,}91\) м \(\gt l_1 = 0{,}9\) м — точка лежит за пределами первого участка. Эпюра \(N_z\) на первом участке через ноль не проходит, значит, экстремума на эпюре перемещений нет: на первом участке перемещение монотонно убывает от 0 до \(-0{,}455\) мм.

Правила построения эпюры перемещения

  1. В заделке перемещение отсутствует: \(\delta(0) = 0\).
  2. На втором и последующих участках \(\delta = \delta_1 + \delta_2 + \ldots\) с учётом знака.
  3. На участке с переменной нагрузкой \(\delta\) — парабола (первый участок).
  4. Если эпюра \(N_z\) проходит через ноль, на эпюре \(\delta\) будет экстремум (здесь не проходит).
  5. \(N_z \lt 0\) — эпюра \(\delta\) убывает (первый участок), \(N_z \gt 0\) — возрастает (второй и третий).
  6. Если \(N_z\) убывает — выпуклость параболы вверх, если \(N_z\) растёт — вниз. На первом участке \(N_z\) растёт от \(-91\) до \(-1\) кН — выпуклость вниз.
  7. \(N_z = \text{const}\) — прямая линия (второй и третий участки).

5. Проверка жёсткости всех участков бруса

\([\Delta l]\) — допускаемое растяжение/сжатие на участке, \([\Delta l] = 10^{-3}\cdot l\). Условие жёсткости: \(|\delta_i| \le [\Delta l]_i\).

Первый участок

$$[\Delta l]_1 = 10^{-3}\cdot0{,}9 = 0{,}9\ \text{мм};\qquad |\delta_1| = 0{,}455\ \text{мм} \le 0{,}9\ \text{мм}.$$

Условие жёсткости не нарушено.

Второй участок

$$[\Delta l]_2 = 10^{-3}\cdot2 = 2\ \text{мм};\qquad |\delta_2| = 1{,}2\ \text{мм} \le 2\ \text{мм}.$$

Условие жёсткости не нарушено.

Третий участок

$$[\Delta l]_3 = 10^{-3}\cdot0{,}6 = 0{,}6\ \text{мм};\qquad |\delta_3| = 0{,}36\ \text{мм} \le 0{,}6\ \text{мм}.$$

Условие жёсткости не нарушено.

Вывод: условие жёсткости выполняется на всех трёх участках бруса, увеличивать площадь сечений или менять материал не требуется.
